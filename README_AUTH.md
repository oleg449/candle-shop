# Система регистрации пользователей для интернет-магазина свечей

## Обзор системы

Полноценная система регистрации и аутентификации пользователей с базой данных, интегрированная с существующим интернет-магазином свечей.

## Технологический стек

**Backend:**
- Node.js + Express
- SQLite база данных
- JWT токены для аутентификации
- bcryptjs для хеширования паролей
- express-validator для валидации

**Frontend:**
- HTML/CSS/JavaScript
- Интеграция с существующим интерфейсом
- Responsive дизайн

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Отредактируйте файл `.env` и измените JWT_SECRET на более безопасный ключ:

```env
JWT_SECRET=ваш-супер-секретный-ключ-для-продакшена
PORT=3000
```

### 3. Запуск сервера

```bash
# Для разработки (с автоперезагрузкой)
npm run dev

# Для продакшена
npm start
```

Сервер запустится на `http://localhost:3000`

## Функциональность

### Для пользователей:

1. **Регистрация** - создание нового аккаунта
2. **Вход в систему** - аутентификация существующих пользователей
3. **Профиль пользователя** - просмотр и редактирование личных данных
4. **Бонусная система** - синхронизация бонусных звезд с сервером
5. **Безопасный выход** - завершение сессии

### Для администраторов:

- Все пользователи хранятся в базе данных SQLite
- Пароли хешируются с помощью bcrypt
- JWT токены для безопасной аутентификации
- Валидация данных на сервере

## API Endpoints

### Аутентификация
- `POST /api/register` - Регистрация нового пользователя
- `POST /api/login` - Вход в систему

### Профиль пользователя (требует аутентификации)
- `GET /api/profile` - Получить данные профиля
- `PUT /api/profile` - Обновить данные профиля

### Бонусная система (требует аутентификации)
- `POST /api/bonus/add` - Добавить бонусные звезды
- `POST /api/bonus/use` - Использовать бонусные звезды

## Использование

### 1. Регистрация нового пользователя

1. Перейдите на `http://localhost:3000/auth.html`
2. Переключитесь на вкладку "Реєстрація"
3. Заполните все обязательные поля
4. Нажмите "Зареєструватися"

### 2. Вход в систему

1. Перейдите на `http://localhost:3000/auth.html`
2. Введите логин/email и пароль
3. Нажмите "Увійти"

### 3. Управление профилем

1. После входа нажмите на свое имя в заголовке
2. Выберите "Мій профіль"
3. Просматривайте и редактируйте свои данные

## Интеграция с существующим сайтом

Система полностью интегрирована с существующим интернет-магазином:

- **Заголовок сайта** показывает кнопки входа/регистрации для гостей
- **Для авторизованных пользователей** отображается приветствие и меню профиля
- **Бонусная система** синхронизируется с сервером для авторизованных пользователей
- **Совместимость** с существующей системой бонусов для гостей

## Безопасность

- Пароли хешируются с помощью bcrypt (10 раундов)
- JWT токены с истечением срока действия (24 часа)
- Валидация данных на клиенте и сервере
- Защищенные API endpoints
- CORS настроен для безопасности

## Структура базы данных

```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  email TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  firstName TEXT,
  lastName TEXT,
  phone TEXT,
  address TEXT,
  bonusStars INTEGER DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
